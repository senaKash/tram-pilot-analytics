# Матрица парка: выбор компонента

Для ячейки с двумя пропорциональными цветами и клика по всей строке использован установленный `st.components.v2`. Штатный `st.dataframe` не рисует две вертикальные доли в одной ячейке, а выбор Plotly не охватывает номер трамвая и пустую часть строки.

`dashboard/components/fleet_matrix.py` создаёт обычные HTML-кнопки. Номер, ячейки и свободное пространство входят в одну кнопку; Enter и Space работают штатно. Данные из PostgreSQL передаются как структурированные значения и выводятся через `textContent`, без HTML из БД. Подсказка содержит счётчики и интервал.

`FleetQueries` агрегирует Track и новые эпизоды отдельно. `FleetService` формирует доли, цвета и подписи. `FleetNavigation` хранит контекст пользовательской сессии. После клика сервер в новом снимке БД проверяет актуальную публикацию и доступность трамвая.

Компонент не обращается к DOM Streamlit, не загружает внешние библиотеки и не меняет правила аналитики.
